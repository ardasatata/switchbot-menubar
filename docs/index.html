Privacy Policy

Last updated: 2026-09-07

This is the privacy policy for the macOS menu bar app published from github.com/ardasatata/switchbot-menubar ("the app"). The app is an independent, unofficial client for the SwitchBot API and is not affiliated with, endorsed by, or operated by SwitchBot / Wonderlabs.

Data collection

The app collects no data of any kind. It has no analytics, no crash reporting, no advertising, and no backend server of its own. Nothing about you or your use of the app is sent to the developer.

Your SwitchBot credentials

On first launch, the app asks for a SwitchBot Open Token and Secret Key that you generate yourself from your own SwitchBot account. These are stored locally on your Mac in the macOS Keychain and are never transmitted anywhere except directly to SwitchBot's own API server (api.switch-bot.com) over HTTPS, using the request signing SwitchBot's API requires. The developer never sees, receives, or has access to your token, secret, or device data.

Network access

The only network requests the app makes are directly from your Mac to api.switch-bot.com, to list your devices and send commands you initiate. No other host is contacted.

Demo Mode

Demo Mode uses only bundled, simulated data and makes no network requests at all.

Third parties

The app does not share information with any third party, because it does not collect any information to share.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL, and the "Last updated" date above will change accordingly.

Contact

Questions or concerns: open an issue at github.com/ardasatata/switchbot-menubar/issues.
